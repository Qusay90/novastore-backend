## Policy authority

`themePlatformExperiencePolicy.js` defines the finite capability registry. BASIC, ADVANCED, PRO and CUSTOM are persisted editor profiles, distinct from billing plans. Effective decisions combine the profile, service grants/denies, the original feature catalog/billing ceilings and freshly read role/session/store authority. Explicit DENY wins. Unsupported custom code, AI, scheduling and direct publishing stay HIDDEN and cannot be granted.

Every configured-service save carries both draft revision and service policy revision. The server computes which fields changed and checks their capabilities. Client hiding is only presentation. A revoked grant cannot be restored by an old open editor or an idempotency replay. Policy changes preserve assignments. Profile edits also invalidate the policy revision of dependent services.

Seller-as-seen is generated by the server for a real active Seller principal in the chosen store; no delegated write token is created. The preview transport is read-only. An absent valid Seller principal must fail visibly, not synthesize a permissive role. Actual Admin editing uses the same core with Admin role capabilities.

## Offers and assets

The eight-step composer persists a CONFIGURED offer referencing an immutable ThemeVersion. Preparing atomically updates the service experience, creates the assignment and initial draft/history, writes the operation ledger, audit and outbox, and records `PREPARED_FOR_DELIVERY`. This does not claim a Stocky receipt or a live deployment. An existing active channel assignment cannot be silently replaced.

Theme packages carry an exact renderer/schema, component registry, capability/channel declaration and hashed raster assets. Bytes are quarantined, fully decoded/reencoded with pinned Sharp, stored outside the public tree and hash-checked before READY. Scoped authenticated routes deliver bytes. Database rollback removes only bytes created by that invocation. Legacy screenshots are explicitly marked stale until captured against the canonical renderer/document digest. The existing HTML demo library is not executed as a trusted package.
